The demo takes an afternoon; making it trustworthy takes months — and the model was never the hard part. Production AI is ten percent model, ninety percent plumbing. This book walks the ninety in the order you meet it building a real agent: memory that updates instead of hoards, retrieval that admits what it hasn't indexed, knowledge that keeps its structure, orchestration as many small minds behind one honest gate, evals that expect to be gamed, an attention budget spent on purpose. Underneath them all, one discipline: don't trust the model — make the structure carry the guarantee.

Fittingly, an agent stack wrote it — ten agents, one chapter each, grounded in the author's own working notes.
