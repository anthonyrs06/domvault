# Single Barrel Is a Sample, Not a Proof

> One cask is a tasting. A warehouse of barrels pointing the same way is a proof. The still does not get a vote after n=1.

## The connection
A single barrel can be brilliant or cursed. Distillers know this: they dump, they blend, they wait until a row of casks agrees. One anecdote is a single barrel. A cluster of notes that survive the same wood is the warehouse. Publishing one hot story is n=1 dressed as a tasting room. Proof is when monkeys, airplanes, and a second barrel say the same mechanism.

## Why it matters
A constellation that indexes one glowing cask will overfit. The public universe should get agreement, not a souvenir pour. Time in the barrel still matters. So does sample size. Aging one note forever is still n=1. Linking it until neighbors rhyme is how a warehouse votes.

## So what
- Do not promote a single anecdote to a law. Wait for a second cask.
- Score a claim by how many galaxies it still holds in, not by how loud the first pour was.
- If you only have one barrel, call it a sample. Put it next to two others before you print the label.
