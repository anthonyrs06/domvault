# A Returned Groom Is the Receipt

> Reciprocity is how the graph confirms an edge. One-way grooming is a stare wearing a gift. The receipt is the sit that came back.

## The connection
In a macaque troop, a groom that never returns is not generosity. It is a one-way stare. The graph only writes the edge when the sit comes back. Costly time offered is a proposal. Costly time returned is the receipt. A second brain that links out and never gets a wiki-link back has sent a gift into a void. Publishing a planet with no inbound grooms is arriving as a donor the troop never signed for. The API is not the first pick. The API is the bout that answered.

## Why it matters
Most vaults celebrate outbound degree and ignore the receipt. The troop does not. An unpaid groom trains the next sitting to go elsewhere. Isolation spreads from a missing return as surely as from a missing offer. The constellation should see edges that cleared, not gifts that never got a signature. A wiki-link you never received is not humility. It is an unconfirmed protocol.

## So what
- Treat an unanswered wiki-link as an unconfirmed edge, not as a completed groom.
- Sit back. Reciprocity is the receipt. Outbound degree without a return is a stare.
- When you publish, leave room for the troop to sign. Then wait for the sit that comes back.
