# A Corridor Is Shared Time, Not Shared Ownership

> Hallways work because cats time-share them. Wiki-links are corridors. Forcing one note to own the hallway is how fights start.

## The connection
Felids share a house by corridor, not by pack. A hallway at six, a sill at noon, a shelf that is not a throne. Overlap is not merger. The peace is a schedule, not a deed. Wiki-links work the same way. Two notes can occupy the same hallway at different hours. Forcing one note to own the link is a stare. A synthesis corridor is shared time. A merge that crowns a winner is a fight about the carpet.

## Why it matters
Knowledge graphs fail when they treat a shared hallway as duplication to delete. Two notes on one corridor can both be true at different hours. Publishing a planet is opening a hallway another star can walk without a fight. If two ideas scrape fur, write the time-share. Do not put a lock on the door and call it hygiene.

## So what
- When two notes overlap, write a corridor, not a deed.
- Treat a wiki-link as shared time. Occupied space can be scheduled. Rank cannot.
- If a fight starts, someone tried to own the hallway. Give it back to the clock.
