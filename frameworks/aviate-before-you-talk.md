# Aviate Before You Talk

> Aviate, navigate, communicate. Fly the airplane before you talk to the field. Capture before you file a heading. Publish is the radio, not the yoke.

## The connection
The first rule in a cockpit is still the same: fly the airplane. Then know where you are. Then talk. Crews that talk first stall with a perfect radio call. A second brain that announces a note before it can still fly — no capture, no hold-private, no alternate — is talking to the field with the wings already mushy. Publish is communicate. Capture is aviate. Filing a heading you cannot hold is a radio call that will not save the stall.

## Why it matters
Competence hides the reversal. The note already feels like a transmission, so you skip the yoke. Vaults that lead with the public map and trail the private airplane are the ones that bend metal. The constellation should get planets that were still flyable when they called, not performances that called and then looked for airspeed.

## So what

- If you cannot still fly the note, you are not cleared to talk. Get the nose down.
- Treat an unpublished rewrite as flying the airplane. Treat a premature publish as a radio call in a stall.
