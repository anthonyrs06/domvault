# Isolation Is Contagious Along the Edge

> A node with no incoming grooms teaches neighbors to stop offering. Missing degree spreads. A second brain that never links out goes quiet the same way.

## The connection
Isolation is not a private mood. In a macaque troop, a node with no incoming grooms is a lesson: sitting here returns nothing, so the next bout goes elsewhere. Missing degree spreads along the edge. Neighbors stop offering. The isolate becomes a region. A second brain does the same thing when a note never links out. Other notes learn not to reach. The quiet is not humility. It is a protocol that trained the graph to skip you.

## Why it matters
